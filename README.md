# 🌐 Site Tag.vc

Site institucional desenvolvido do zero para a **Tag.vc**, com foco em apresentação da empresa, organização das informações e experiência de navegação.

O projeto foi desenvolvido utilizando tecnologias web fundamentais, com estrutura de páginas, componentes visuais, estilização e recursos de interação.

---

## 🎯 Objetivo

Desenvolver um site institucional responsivo para apresentar a empresa e seus serviços, organizando as informações de forma clara e proporcionando uma experiência de navegação simples e intuitiva.

---

## ✨ Características

* Desenvolvimento de site do zero
* Estrutura de múltiplas páginas
* Interface responsiva
* Organização de conteúdo
* Navegação entre páginas
* Componentes visuais personalizados
* Estilização utilizando CSS
* Interações utilizando JavaScript
* Estrutura sem dependência de frameworks front-end

---

## 🛠️ Tecnologias

* **HTML5**
* **CSS3**
* **JavaScript**
* **JSON**

### Principais conceitos utilizados

`Responsive Design` `Layout Web` `DOM` `JavaScript` `CSS` `HTML Semântico`
